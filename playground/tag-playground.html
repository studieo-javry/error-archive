ErrorCase Tag Playground

free-tag 위젯 UX 확인용. 모든 호출은 게이트웨이(http://localhost:8000) 거쳐 core-api 로.

① 기존 케이스에서 태그 편집 (단건 add / remove)

아직 로드되지 않음.
정규화: trim · lowercase · ≤32자 · 케이스당 max 20개.

② 새 케이스 + 태그 일괄 생성

도움말

  • 이 파일은 file:// 로 열면 CORS 가 막힘. 반드시 다음 중 하나로 서빙: 
    cd playground && python3 -m http.server 3000
# 또는 5173
    그리고 http://localhost:3000/tag-playground.html 열기.
  • JWT 는 90초~ 단명 토큰이라 401 이 나면 다시 mint. (기본 mint-jwt.sh 출력 시간 확인)
  • 모든 호출/응답은 우측 패널 Network log 에 표시.
